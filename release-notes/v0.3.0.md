## Six languages and light or dark appearance

### Added

- Choose English, Russian, French, German, Spanish, or Italian in **Settings → Appearance**. Preferences, the brightness popup, schedule controls, shortcut feedback, native tray actions, and update controls use the selected language immediately.
- Switch between light and dark themes in the same Appearance group. Both themes provide consistent text, controls, cards, sliders, selection, and warning colors.
- Language and theme preferences persist in normal and portable settings. Older settings retain brightness memories, schedules, shortcuts, and startup-update preferences while defaulting to English and the existing dark appearance.

### Improved

- Known application/service notices update their language at display time; monitor model names, file paths, Windows diagnostics, and release-note contents remain unchanged.
- Developer self-capture supports explicit language and theme fixtures and a bounded timeout, using the production CPU renderer and simulated monitors.

### Validation

Catalog checks verify complete translations and preserved message arguments. Persistence checks cover older settings and every supported language with a saved light theme. Automated checks and visual evidence for this version are recorded in the accompanying verification notes.

Download **MultiMonitorBrightness-v0.3.0.exe** for Windows 10/11 x64, or use **Settings → Updates → Download and install** from v0.2.1 or newer. Existing settings are preserved. Version 0.2.0 requires the previously documented one-time manual upgrade because its updater expects the old asset name.
