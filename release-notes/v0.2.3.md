## Larger, clearer tray icon

### Improved

- The tray sun is approximately 50% larger than in v0.2.2, with thicker, rounded rays and a transparent background so it is easier to recognize beside other notification-area icons.
- The tray artwork is drawn at the Windows small-icon size with antialiased edges, instead of shrinking the executable's padded icon. The executable and window keep their existing artwork.

### Validation

Reviewed the actual tray artwork at 16, 20, 24, and 32 pixels on light and dark backgrounds. Rust formatting, Clippy, and 24 automated tests passed. Controlled release-mode checks for Settings, the brightness popup, hidden startup, and a simulated slider drag passed: unchanged idle scenes produced zero rasterizations, and hidden windows produced zero paints.

Download **MultiMonitorBrightness-v0.2.3.exe**. Windows 10/11 x64; no installer or additional runtime required. Versions 0.2.1 and newer can use **Settings → Updates → Download and install**. Users still on 0.2.0 need a one-time manual upgrade because that version expects the old asset name. Existing settings and user data are preserved.
