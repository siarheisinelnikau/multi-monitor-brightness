## Preferences open beside the tray

### Improved

- Settings and Schedule now open beside the tray icon on its monitor, instead of using Windows' default window position on the left side of the screen.
- Restoring a minimized preferences window places it beside the tray again. Switching tabs in an already open window preserves its position, and maximized windows keep their maximized state.
- Placement accounts for the native title bar, window borders, monitor scaling, and available work area so the preferences window stays on screen.

### Validation

Native Windows regression checks verified opening preferences beside the tray, keeping their position when switching tabs, and returning to the tray after moving and minimizing the window. Geometry checks cover 100%, 125%, 150%, and 200% scales and negative monitor coordinates. Formatting, Clippy, and 27 automated tests passed. Controlled release-mode checks produced zero idle rasterizations and zero hidden paints.

Download **MultiMonitorBrightness-v0.2.5.exe** for Windows 10/11 x64, or use **Settings → Updates → Download and install** from v0.2.1 or newer. Existing settings and user data are preserved. Version 0.2.0 still requires a one-time manual upgrade because it expects the old asset name.
