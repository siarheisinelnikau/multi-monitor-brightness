## Brightness, one click away

- Click the tray icon for a compact brightness popup with shared and per-monitor sliders. Click again, press Esc, or click outside to dismiss it.
- Settings and Schedule now open in a separate preferences window, with a simpler graphite and blue interface.
- Check GitHub for updates from Settings or the tray menu. Optional automatic checks run once a day.
- Download and install updates from the app. Downloads are verified with SHA-256 before replacing the executable; the app saves preferences and restarts automatically.
- Start with Windows remains opt-in and launches quietly in the tray. The version appears in Settings.

Download **MultiMonitorBrightness.exe** and run it. Windows 10/11 x64; no installer or additional runtime required. In-app updates need a writable executable folder. External monitors must support DDC/CI.

Validation: automated Rust checks, native tray/window regressions with simulated monitors, an isolated executable replacement/restart regression, and a real GitHub download/checksum check.
