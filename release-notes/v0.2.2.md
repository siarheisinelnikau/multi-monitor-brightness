## CPU rendering for the desktop UI

### Improved

- The brightness popup and preferences now render on the CPU and display through Windows GDI. The Windows executable no longer uses an OpenGL or DirectX rendering backend, while retaining the existing interface and controls.
- Hidden windows skip painting. Unchanged visible scenes reuse the cached bitmap, and Windows expose events restore it without rerasterizing the interface. Pointer/repaint bursts coalesce to the monitor's refresh rate, and the event loop sleeps between input and scheduled work.
- Background schedules, brightness commands, update checks, and tray actions continue while windows are hidden. Texture uploads survive hidden passes so reopening does not lose fonts.

### Fixed

- Closing preferences hides the window without shutting down background work; restoring it and repeatedly opening the brightness popup are covered by native window regressions.
- Window dimensions account for the available work area at larger DPI/zoom scales. The initial popup anchors to the tray icon instead of following the cursor's monitor.
- Opt-in renderer test failures exit with a report instead of showing a diagnostic dialog. These test modes are not included in the normal release executable.

### Validation

Rust formatting, Clippy and unit tests; native tray/window regression; controlled release-mode renderer checks for idle Settings, idle popup, hidden startup, and a simulated slider drag. The controlled five-second idle samples after warm-up produced zero rasterizations, hidden samples produced zero paints, and the tested process loaded no OpenGL/DirectX graphics modules. These measurements do not certify subjective input latency on every computer.

Download **MultiMonitorBrightness-v0.2.2.exe**. Windows 10/11 x64; no installer or additional runtime required. Versions 0.2.1 and newer can use **Settings → Updates → Download and install**. Users still on 0.2.0 need a one-time manual upgrade because that version expects the old asset name. Existing settings and user data are preserved.
