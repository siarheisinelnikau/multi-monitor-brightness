Multi-Monitor Brightness is a portable Windows brightness controller built in Rust.

### New in 0.1.2

- **Start with Windows** in Settings: opt in to launch quietly in the system tray when you sign in. No administrator rights are needed. Portable settings mode is preserved.
- The app version is always visible at the top of Settings and stays in sync with the executable version.
- If autostart points to another copy, **Use this executable** updates the registration.

### Included

- Shared and per-monitor hardware brightness controls for DDC/CI-capable external displays.
- Customizable global hotkeys, per-display brightness memory, and smooth evening dimming.
- Neutral graphite interface with a restrained blue accent and Windows UI font.
- Working tray Open, brightness up/down, and Quit actions, including while the window is hidden.

### Download

Download **MultiMonitorBrightness.exe** and run it. No installer or additional runtime is required. **SHA256SUMS.txt** contains the executable's checksum. Settings normally live in `%APPDATA%\MultiMonitorBrightness`; use `--portable` to keep them beside the executable.

Requires Windows 10/11 x64 and a compatible external monitor. Enable DDC/CI in the monitor's own menu if brightness control is unavailable. Built-in laptop screens and some docks are not supported.

Autostart is disabled by default. Enable it in **Settings → Application → Start with Windows**. Keep the executable in a stable location.
