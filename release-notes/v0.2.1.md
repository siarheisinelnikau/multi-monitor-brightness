## Consistent release downloads

### Improved

- The Windows download now includes the product version: **MultiMonitorBrightness-v0.2.1.exe**. Build output, release uploads, README links, and SHA-256 checksums use the same name. This release offers Windows x64 only, so no architecture suffix is needed.
- The in-app updater selects the executable matching the release version and verifies the checksum for that exact filename. Installation preserves settings, the installed executable's filename, and its existing startup path.
- README now includes real screenshots of the brightness popup, Settings, and Schedule, plus download and upgrade instructions.

### Fixed

- Automatic update checks now run in the background shortly after every startup, including when an earlier check happened the same day. **Check for updates on startup** disables these requests persistently; manual checks remain available.

### Upgrading from 0.2.0

Download **MultiMonitorBrightness-v0.2.1.exe** manually, quit the old app from the tray, and replace the previous executable. Version 0.2.0 expects the old asset name and cannot install the new versioned downloads. Existing AppData settings are kept. Portable users should keep `multi-monitor-brightness.json` beside the executable and use `--portable`. If the installed filename changes, update **Settings → Application → Use this executable** when Windows startup is enabled. Future in-app updates from 0.2.1 support versioned release assets.

Windows 10/11 x64; one executable, no installer or additional runtime. External monitors must support DDC/CI.
